# 🎓 بوابة مسار - Massar Student Portal

واجهة أمامية كاملة لبوابة التلميذ الإلكترونية مستوحاة من نظام مسار المغربي.

## 🚀 تشغيل المشروع

لا يحتاج المشروع إلى أي تثبيت! فقط افتح الملف:

```
index.html
```

مباشرة في المتصفح (Chrome / Firefox / Edge).

## 🔐 بيانات الدخول

| الحقل | القيمة |
|-------|--------|
| رقم مسار | `G123456789` |
| كلمة المرور | `123456` |
